How the calculator works Formulas & assumptions

Available agents = scheduled agent headcount − unavailable agents (shrinkage), with a minimum of zero. Shrinkage is a headcount, not a percentage. It is deducted from agents only; support call contribution is configured separately.

Daily call-handling time per available agent = shift seconds − daily ACW seconds, with a minimum of zero. ACW is the total wrap-up time for one available agent over the whole day, deducted once. The default 8.5-hour shift is 510 minutes. The ACW slider allows 60–150 minutes; the goal is marked in green at 90 minutes and current ACW in red at 120 minutes. Both are editable in Admin, with a warning above the current benchmark.

Calls per available agent = daily call-handling time ÷ AHT. AHT is talk and hold time per call, excluding ACW. AHT must be greater than zero. Click the green 5:00 goal or red 5:30 current benchmark to apply it; both values are editable in Admin.

Displayed daily average is calls per available agent. Headcount, reserve staffing, and shrinkage do not change this productivity figure; they change total team capacity. With zero available agents, the average still shows potential calls per available agent, while team capacity is zero.

Support / reserve HC adds agents who handle calls. Each reserve contributes 100% of an available agent’s capacity by default, using the same AHT and daily ACW. Use Admin to set a lower contribution for part-day support. Shrinkage is deducted from primary agents; reserve agents are additional available coverage.

Available calls on each weekday show the same daily team capacity. Covered demand is capped at incoming calls for that day; shortfall is any demand above capacity.

Team capacity = calls per available agent × (available agents + support × support contribution %). Fractional calls are retained until team capacity is rounded down. Support uses the same daily ACW and AHT when it contributes to calls.

Reverse planning checks staffing options and solves the selected variable—AHT or daily ACW—to meet the chosen day's demand and calls-per-available-agent target. The other productivity setting and unavailable agent headcount stay fixed. Staffing follows the admin support ratio. Rounding and slider limits may prevent an exact target; actual capacity and shortfall are always shown.

Capacity is not a response-time SLA. This model assumes demand can be handled throughout the shift. Arrival patterns, queues, occupancy buffer, abandonment, and interval staffing are not modeled. Daily ACW and unavailable agent headcount do not account for any additional breaks or meetings taken by available agents.

How Campaign planning works Targets, predictions & assumptions

Week-wide demand. The Queued calls slider scales all five weekdays together, using the selected day as the reference and retaining their relative volumes. Individual weekday totals can be edited in Admin. If the reference day has zero calls, moving the slider starts all five days at the chosen volume.

Staffing batteries. Green shows how much of your current primary headcount is needed; unused space represents spare headcount. When more staff are required than you have, red shows the additional requirement. Headcount changes in whole agents, and wait/service targets can limit the effect of an abandonment change.

Targets and linked totals. Abandoned target calls = queued calls × abandonment target %, rounded to whole calls. Handled target calls = queued − abandoned. Moving either count slider adjusts the abandonment target; moving that percentage updates both counts. Counts always reconcile. Target counts describe the allowed scenario; modeled outcomes at the recommended staffing can be better.

Required headcount. An Erlang A queue model finds the smallest number of agents on calls at once that meets all three targets: maximum abandonment rate, maximum average wait for answered calls, and minimum service level. Service level means calls answered within the configured threshold divided by all queued calls, including every abandonment. The default is 77% within 120 seconds.

Average abandonment time. The 90-second input is used as an assumed mean caller patience with an exponential distribution. It is not a fitted estimate from observed abandoned calls. The average time of callers who actually abandon can differ from overall caller patience, and this input alone cannot identify that distribution.

Shared Agent settings. Weekday demand, AHT, and daily ACW are shared with Agent view. The Campaign ACW slider is the same daily total per available agent used in Agent view; changing it updates both dashboards. Required agents on calls are converted to primary scheduled headcount using shift length, daily ACW, unavailable agents, and reserve contribution from Agent view. ACW is spread across the day as an availability allowance; no extra per-call ACW is added. The current Agent headcount is a comparison, not a limit on Campaign requirements.

Operating assumptions. Calls arrive randomly at a constant average rate over the configured operating hours. Service and patience times are exponential, calls wait in a single first-come queue, and callers do not retry or transfer. Daily totals hide busy intervals. No separate occupancy ceiling is imposed. Results are scenario estimates, not a prediction of an actual day's service or a staffing schedule.

Reference model. Garnett, Mandelbaum & Reiman: Designing a Call Center with Impatient Customers (2002).

How the calculator works Formulas & assumptions

Per-agent calls = shift seconds × (1 − shrinkage %) ÷ (AHT seconds + ACW seconds). This is a daily average; fractional calls are retained until team capacity is rounded down.

Team capacity = calls per agent × (agents + support × support contribution %). All staff use the same shift and shrinkage. Support contribution defaults to 0%; support staff then provide oversight without taking calls.

Reverse planning has many possible answers. Select AHT, ACW, or shrinkage to solve while holding the other two fixed. Agent and support counts are then sized for the selected day, using the admin support ratio. Limits can make targets impossible; the actual achievable capacity and shortfall remain visible.

AHT excludes ACW in this model. If your reporting AHT already includes ACW, enter ACW as 0 to avoid double counting. Include breaks, leave, meetings, and other unavailable time in shrinkage once.

Capacity is not a response-time SLA. This model assumes demand can be handled throughout the shift. Arrival patterns, queues, occupancy buffer, abandonment, and interval staffing are not modeled. 100% daily coverage does not guarantee an answer-speed SLA.

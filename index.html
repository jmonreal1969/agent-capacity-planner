How the calculator works Formulas & assumptions

Available agents = scheduled agent headcount − unavailable agents (shrinkage), with a minimum of zero. Shrinkage is a headcount, not a percentage. It is deducted from agents only; support call contribution is configured separately.

Daily call-handling time per available agent = shift seconds − daily ACW seconds, with a minimum of zero. ACW is the total wrap-up time for one available agent over the whole day, deducted once. The default 8.5-hour shift is 510 minutes. The ACW slider allows 0–180 minutes; the daily maximum is marked at 90 minutes, with a warning above it for scenario planning.

Calls per available agent = daily call-handling time ÷ AHT. AHT is talk and hold time per call, excluding ACW. AHT must be greater than zero.

Calls per scheduled handler = total unrounded team capacity ÷ (primary agent headcount + reserve call-handling equivalents). Reserves contribute to both capacity and this average. A part-day reserve is weighted by the Admin contribution percentage. Unavailable primary agents remain in the scheduled count; zero scheduled handlers gives an average of zero.

Support / reserve HC adds agents who handle calls. Each reserve contributes 100% of an available agent’s capacity by default, using the same AHT and daily ACW. Use Admin to set a lower contribution for part-day support. Shrinkage is deducted from primary agents; reserve agents are additional available coverage.

Team capacity = calls per available agent × (available agents + support × support contribution %). Fractional calls are retained until team capacity is rounded down. Support uses the same daily ACW and AHT when it contributes to calls.

Reverse planning checks staffing options and solves the selected variable—AHT, daily ACW, or unavailable agent headcount—to meet the chosen day's demand and calls-per-scheduled-handler target. The other two variables stay fixed. Staffing follows the admin support ratio. Rounding and slider limits may prevent an exact target; actual capacity and shortfall are always shown.

Capacity is not a response-time SLA. This model assumes demand can be handled throughout the shift. Arrival patterns, queues, occupancy buffer, abandonment, and interval staffing are not modeled. Daily ACW and unavailable agent headcount do not account for any additional breaks or meetings taken by available agents.
